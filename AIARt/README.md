this folder contains the AR App used for the AI-Experiment.


to run it independently you will need to copy the aframe and mindAR javascript files.

the targets.mind file needs to be generated for the specific images and this can be done here: [https://hiukim.github.io/mind-ar-js-doc/tools/compile/](https://hiukim.github.io/mind-ar-js-doc/tools/compile/)


The script chooses a video for each image randomly when the application is loaded. The detection is encoded in the targets.mind file. Lots of the weird code at the bottom of the script is just to force modern browsers to autoplay the videos.

The code was AI generated with lots of prompting
